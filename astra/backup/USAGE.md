# Инструкция по использованию — astra-backup

Всё лежит в `D:\ClaudeCode\astra-backup`. Скрипты на **bash** — запускать в
**Git Bash** (Windows) или на Linux-сервере.

## 1. Скачивание сборок

Скачать всё доступное с 2025 года в `./archive`:

```bash
./backup-astra.sh
```

Повторный запуск качает **только новое**, дубликатов не создаёт. Ставьте в cron /
планировщик — архив будет поддерживаться в актуальном состоянии.

Полезные флаги:

```bash
./backup-astra.sh --start 2024-06-01
```

```bash
./backup-astra.sh --archive /mnt/raid5/astra-archive
```

- `--start ГГГГ-ММ-ДД` — с какой даты качать (смена даты **не удаляет** уже скачанные
  файлы, только до-качивает недостающее);
- `--end ГГГГ-ММ-ДД` — по какую дату (по умолчанию — сегодня);
- `--full` — перепроверить весь диапазон, игнорируя кэш «пустых» дат;
- `--delay 0.2` — пауза между запросами, чтобы щадить сервер.

## 2. Настройка FTP

Отредактируйте `config.env` — впишите реквизиты:

```ini
FTP_HOST="ftp.example.com"
FTP_PORT=21
FTP_USER="user"
FTP_PASS="secret"
FTP_DIR="/astra"
FTP_TLS=0          # 1 = FTPS explicit (AUTH TLS)
```

Закройте файл от чужих глаз (пароль в открытом виде):

```bash
chmod 600 config.env
```

## 3. Выгрузка на FTP

Заливает **только те файлы, которых на сервере ещё нет** (сверка со списком сервера):

```bash
./upload-ftp.sh
```

С проверкой размера уже лежащих файлов (перезальёт недокачанные ранее):

```bash
./upload-ftp.sh --verify
```

## 4. Всё сразу (скачать + выгрузить)

```bash
./sync-all.sh
```

## 5. Автоматизация (cron, каждый день в 03:30)

```bash
crontab -l 2>/dev/null | { cat; echo "30 3 * * * /d/ClaudeCode/astra-backup/sync-all.sh >> /var/log/astra-backup.log 2>&1"; } | crontab -
```

---

## Как это работает / что важно

- Файлы называются `astra-ГГММДД` (напр. `astra-250325` = 25.03.2025), лежат в `archive/`.
- Уже скачанное пропускается без обращения к сети; «пустые» даты кэшируются
  (`state/missing.txt`) и перепроверяются только за последние 45 дней (`RECHECK_DAYS`).
- Загрузка атомарная (`*.part` → переименование) — обрыв связи не оставит битых файлов.
- Смена `START_DATE` / `--start` **никогда не удаляет** старые файлы.

Полная версия и тонкости (FTPS implicit, SFTP, безопасность) — в `README.md`.
