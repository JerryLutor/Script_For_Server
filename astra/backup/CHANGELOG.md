# Changelog

Формат версий: X.Y.Z — X=0 (мажор до отдельного указания), Y=завершённые пункты плана,
Z=мелкие правки.

## 0.1.0 — 2026-09-13

Первая версия.

- `backup-astra.sh` — инкрементальное скачивание сборок Astra `astra-ГГММДД` с
  `http://cesbo.com/and/` от `START_DATE` (по умолчанию 2025-01-01) до сегодня.
  - перебор дат (листинга каталога у сервера нет: 403);
  - пропуск уже скачанного без запроса; кэш «отсутствующих» дат `state/missing.txt`
    с окном перепроверки `RECHECK_DAYS` (по умолчанию 45);
  - атомарная загрузка (`*.part` → `mv`), устойчивость к обрывам, `--retry`;
  - флаги `--start/--end/--archive/--recheck-days/--delay/--full`;
  - смена `START_DATE` не удаляет ранее скачанные файлы.
- `upload-ftp.sh` — выгрузка на FTP только новых файлов (сравнение по списку сервера),
  FTPS explicit (`FTP_TLS=1`), пароль через временный curl-конфиг (не виден в `ps`),
  флаг `--verify` для сверки размеров и перезаливки битых.
- `sync-all.sh` — скачивание + выгрузка одной командой (для cron).
- `lib.sh`, `config.env`, `.gitignore`, `README.md`, `HANDOFF.md`.
